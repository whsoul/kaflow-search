# Kaflow Search 개인정보 처리방침

**버전: 1.0-beta**
**최종 갱신일: 2026-08-11**

> 본 문서는 영어 원문의 한국어 번역본입니다. 번역본과 영어 원문이 충돌하는 경우, 적용 법률이 달리 요구하지 않는 한 영어 원문이 우선합니다.

본 개인정보 처리방침은 Kaflow Search("본 소프트웨어")가 어떤 정보를 처리하는지, 무엇이 귀하의 기기 밖으로 전송되는지, 그리고 라이선서(Whsoul Tools)가 무엇을 수신·보유하는지를 설명합니다.

Kaflow Search는 데스크톱 애플리케이션입니다. 핵심 설계 원칙은 **귀하의 Kafka 데이터는 귀하의 기기에 머무른다**는 것입니다.

## 1. 로컬에만 머무는 것 (라이선서에게 전송되지 않음)

다음 데이터는 귀하의 기기에서만 처리·저장되며, 라이선서에게 절대 전송되지 않습니다:

- Kafka 메시지 내용(키, 페이로드, 헤더) 및 토픽명;
- 로컬 검색 인덱스 및 인덱스 메타데이터;
- 검색어 및 검색 결과;
- 클러스터 주소, 연결 설정 및 스키마 레지스트리 설정;
- 인증 자격증명(본 소프트웨어는 비밀번호를 디스크에 저장하지 않으며, 세션마다 다시 입력받습니다);
- 내보내기 파일 및 백업;
- 애플리케이션 설정.

본 소프트웨어는 귀하의 Kafka 데이터를 **귀하가 직접 설정한** Kafka 클러스터 및 스키마 레지스트리에만, 귀하가 실행하는 기능의 수행에 필요한 범위에서 전송합니다. 해당 시스템은 귀하(또는 귀하의 조직)의 것이며, 그 시스템에서의 데이터 취급은 라이선서의 통제 밖에 있습니다.

## 2. 호환성 확인(app-check) 요청

본 소프트웨어는 시작 시(및 실행 중 주기적으로) 버전 호환성과 서비스 정책을 확인하고 안내 콘텐츠를 수신하기 위하여 라이선서의 온라인 서비스에 접속합니다. 각 요청에는 다음의 제한적인 기술 정보만 포함됩니다:

| 항목 | 내용 | 목적 |
|---|---|---|
| `appInstanceId` | 최초 실행 시 로컬에서 생성되는 무작위 UUID. 개인정보를 포함하지 않으며, 애플리케이션 데이터 삭제 시 재생성됨. | 요청 상관관계 파악, 속도 제한, 어뷰징 감지 |
| `deviceIdHash` | 운영체제 머신 식별자의 SHA-256 해시. 원본 식별자는 기기를 떠나지 않으며 해시로부터 복원할 수 없음. | 어뷰징 감지(예: 복제 설치 탐지) |
| `appVersion` | 본 소프트웨어의 버전 | 업데이트·호환성 판정 |
| `platform`, `arch` | 운영체제 및 CPU 아키텍처 | 호환성 판정 |
| `locale` | UI 언어 | 서비스 메시지 현지화 |

본 소프트웨어는 귀하의 IP 주소를 전송하지 않습니다. 인터넷을 통한 모든 요청이 그러하듯 호스팅 제공자는 요청을 라우팅하고 응답하기 위해 접속 IP 주소를 보게 되지만, 서비스는 이를 기록하거나 해시하거나 저장하지 않습니다.

이 요청에는 Kafka 메시지 내용, 토픽명, 클러스터 주소, 자격증명, 검색어 등 귀하의 작업 내용이 포함되지 않습니다.

**보유 기간:** 라이선서는 이 요청을 데이터베이스에 저장하지 않습니다. 요청은 호스팅 플랫폼의 운영 로그에만 남으며, 해당 플랫폼이 짧은 기간(개월이 아닌 일 단위) 보관한 후 폐기합니다. 라이선서는 이를 다른 곳으로 복사하지 않습니다.

## 3. 진단 리포트 (사용자 요청 시에만)

본 소프트웨어는 귀하가 요청하는 경우 진단 리포트를 생성할 수 있습니다. 리포트는 귀하의 기기에 **로컬로** 생성·저장됩니다. 리포트에는 기술적 재현 정보(애플리케이션 버전, 기능 플래그, 타이밍, 오류 분류, 감지된 Kafka 브로커 버전)가 포함되며, 메시지 내용은 제외되도록 설계되어 있습니다.

진단 리포트는 **귀하가 직접 전송하거나 공유하기로 선택한 경우에만** 라이선서에게 전달됩니다. 공유 전에 리포트 파일을 직접 확인할 수 있습니다.

## 4. 향후 기능

추가적인 데이터 처리가 필요한 기능(예: 별도 라이선스가 적용되는 기능)이 향후 도입되는 경우, 해당 기능이 적용되기 전에 본 처리방침의 갱신판에서 추가 처리 내용을 안내합니다.

## 5. 라이선서가 하지 않는 것

- 광고, 광고 추적, 데이터 판매를 하지 않습니다.
- 제2조의 호환성 확인 외의 행태 분석이나 사용 텔레메트리를 수집하지 않습니다.
- Kafka 메시지 내용, 토픽명, 클러스터 주소, 자격증명, 검색어를 수집하지 않습니다.

## 6. 서비스 제공자 및 제공

라이선서는 위 온라인 서비스 운영을 위하여 인프라 서비스 제공자(호스팅, CDN 등)를 이용하며, 이들은 라이선서를 대신하여 데이터를 처리합니다. 법률상 요구되는 경우 정보가 제공될 수 있습니다.

온라인 서비스는 전 세계에 분산된 엣지 플랫폼에서 실행됩니다 — 각 요청은 하나의 고정된 리전이 아니라 귀하와 가장 가까운 위치에서 처리됩니다. 이 서비스가 데이터를 영속적으로 저장하는 경우, 해당 데이터는 아시아·태평양(APAC) 리전에 보관되며 다른 리전으로 복제되지 않습니다.

## 7. 귀하의 권리

적용 법률(대한민국 개인정보 보호법 포함)에 따라, 귀하는 귀하의 식별자와 연관된 정보에 대한 열람, 정정 또는 삭제를 요청할 권리를 가질 수 있습니다.

라이선서는 제2조의 요청을 저장하지 않으므로, 귀하의 식별자와 연관되어 열람·정정·삭제할 기록은 통상 존재하지 않습니다. 위 권리는 라이선서가 실제로 보유하는 정보 — 예컨대 귀하가 직접 공유하기로 선택한 진단 리포트나 아래 주소로 보낸 문의 — 에 적용됩니다.
